# Security policy

Remindable stores all data on the user's device and has no server (see [ADR 0002](docs/adr/0002-local-only-data.md)). Issues that still matter include:
- data leaking off the device
- speech or conversation text being kept longer than intended
- a dependency with a known vulnerability

**Please don't open a public issue for a vulnerability.** Report it through [GitHub private vulnerability reporting](https://github.com/hussmartinez/remindable/security/advisories/new). You'll get a reply within a week.
